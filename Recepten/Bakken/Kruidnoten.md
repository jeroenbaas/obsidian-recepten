# Kruidnoten

> Knapperige, kruidige koekjes die niet mogen ontbreken bij Sinterklaas. Lekker zelfgemaakt!

## 🥘 Ingrediënten

| Ingrediënt | Hoeveelheid | Opmerking |
|------------|-------------|-----------|
| Zelfrijzend bakmeel | 250 g |  |
| Donkere basterdsuiker | 125 g |  |
| Zachte boter | 100 g |  |
| Speculaaskruiden | 2 el |  |
| Zout | snuf |  |
| Melk | 3 el |  |

## 👨‍🍳 Bereiding

1. Zeef het bakmeel boven een kom en maak een kuiltje in het midden.
2. Voeg in het kuiltje de suiker, boter, speculaaskruiden, zout en melk toe.
3. Verkruimel met de vingers door het meel en kneed snel tot een soepel deeg.
4. Verwarm de oven voor op 150°C.
5. Vorm van het deeg kleine balletjes en leg die op de bakplaat.
6. Bak de kruidnootjes in ongeveer 20 minuten bruin en gaar.

## 💡 Tips & Variaties

- Maak de balletjes niet te groot voor de authentieke kruidnootjes
- Bewaar in een luchtdicht blik voor langere houdbaarheid
