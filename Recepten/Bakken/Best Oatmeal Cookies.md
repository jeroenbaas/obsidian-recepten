# Best Oatmeal Cookies

> Knapperige en kauwige havermoutkoekjes met rozijnen en pecannoten. Het geheim is het weken van de rozijnen voor extra smaak!

## 🥘 Ingrediënten

| Ingrediënt | Hoeveelheid | Opmerking |
|------------|-------------|-----------|
| Eieren | 3 stuks | Goed geklopt |
| Rozijnen | 1 cup |  |
| Vanille | 1 tl |  |
| Boter | 1 cup |  |
| Bruine suiker | 1 cup |  |
| Witte suiker | 1 cup |  |
| Bloem | 2½ cups |  |
| Zout | 1 tl |  |
| Kaneel | 1 tl |  |
| Baking soda | 2 tl |  |
| Havermout | 2 cups |  |
| Pecannoten | ¾ cup | Gehakt |

## 👨‍🍳 Bereiding

1. Combineer eieren, rozijnen en vanille en laat 1 uur staan. Dit maakt het verschil!
2. Klop boter en suikers romig.
3. Voeg bloem, zout, kaneel en baking soda toe en meng goed.
4. Meng het ei-rozijnenmengsel, havermout en gehakte noten erdoor.
5. Het deeg zal stevig zijn.
6. Schep met gehapte theelepels op een niet-ingevette bakplaat, of rol balletjes en druk licht plat.
7. Bak op 175°C (350°F) gedurende 10-12 minuten tot lichtbruin.

## 💡 Tips & Variaties

- Het geheim is het weken van de rozijnen - dit maakt alle verschil!
