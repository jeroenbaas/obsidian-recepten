# Kikkererwtensoep met Wortel

> Een voedzame soep van kikkererwten met wortel en oosterse kruiden. Romig gepureerd met een vleugje pit.

## 🥘 Ingrediënten

| Ingrediënt | Hoeveelheid | Opmerking |
|------------|-------------|-----------|
| Kikkererwten | 1 groot blik | Afgespoeld |
| Koriander | 1 flinke bos | |
| Winterpeen | 250 g | |
| Ui | 1 grote | |
| Groentebouillon | 1 liter | + evt. extra |
| Knoflook | 2 tenen | |
| Gember | 3 cm | |
| Korianderzaad | 1 el | |
| Komijnzaad | 1 el | |
| Chilivlokken | | Naar smaak |
| Plantaardige olie | Scheut | |
| Zout & peper | | Naar smaak |

## 👨‍🍳 Bereiding

1. Snipper de ui en fruit in een scheut olie in een soeppan met dikke bodem, ongeveer 10 minuten.

2. Hak de gember en knoflook fijn en voeg toe. Snijd de wortel in plakjes en doe erbij. Voeg ook komijn- en korianderzaad toe. Fruit alles rustig even mee.

3. Voeg de (liefst hete) bouillon toe. Doe dan de afgespoelde kikkererwten erbij.

4. Hou wat koriander achter voor de garnering. Doe de rest in z'n geheel (ook de steeltjes) in de pan, plus zout, peper en wat chilivlokken.

5. Breng aan de kook en laat onder een deksel 15-20 minuten zachtjes sudderen tot de wortel gaar is.

6. Pureer met de staafmixer of in de blender. Verdun eventueel met extra bouillon voor een lichtere soep. Proef op zout en peper.

7. Garneer met de achtergehouden koriander.

## 💡 Tips & Variaties

- Een sliertje room of olijfolie erover is ook lekker
- Maak hem lenteachtig licht of winters voedzaam door de hoeveelheid bouillon aan te passen
