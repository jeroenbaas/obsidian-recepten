# Vegan Waldorf Salade met Appel, Bleekselderij & Walnoten

> Klassieker dan de waldorfsalade kan bijna niet. Onze versie is alleen helemaal vegan en dus extra lekker.

## 🥘 Ingrediënten

### Salade
| Ingrediënt | Hoeveelheid | Opmerking |
|------------|-------------|-----------|
| Witte kool | ½ | |
| Bleekselderij | 1 bos | |
| Zoetzure appels | 3 | |
| Walnoten | 150 g | |
| Rozijnen | 100 g | |

### Dressing
| Ingrediënt | Hoeveelheid | Opmerking |
|------------|-------------|-----------|
| Citroensap | sap van 1 citroen | |
| Appelciderazijn | 15 ml | |
| Sojayoghurt | 200 ml | |
| Knoflook | 1 teentje | geperst |
| Zaanse mosterd | 1 tl | |
| Zout en zwarte peper | naar smaak | |

## 👨‍🍳 Bereiding

1. Snijd de kool in de lengte doormidden en vervolgens op een mandoline in flinterdunne plakjes. Met een scherp mes lukt het ook.

2. Was de bleekselderij goed en snijd de stengels in stukjes van 1 cm. Verwijder het klokhuis en snijd de appels in kleine stukjes. Doe de kool, bleekselderij, appel, walnoten en rozijnen in een grote kom.

3. Meng het citroensap, de appelciderazijn, sojayoghurt, knoflook en mosterd in een kommetje en schep dit door de salade. Voeg tot slot een snuf zout en zwarte peper toe.

## 💡 Tips & Variaties

- Je kunt altijd stukjes (gerookte) kipfilet toevoegen als je dat lekker vindt
